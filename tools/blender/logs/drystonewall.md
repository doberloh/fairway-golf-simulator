# drystonewall: iterations (tools/blender/cartoon_newengland.py)

One line a round: what was wrong beside the reference pictures, and what changed. The side-by-side of each round: bench/shots/blender/iter/cartoon_newengland/drystonewall-r<round>.png (local).

- r1: First build: one 2 m section along Y as the game wants, four courses of rounded stones, a few lichened. The sheet's camera looks along Y, so it shows only the end: a narrow stack. Next: one round built along X to judge the run against the pictures, then back to Y.
- r2: Review round along X: a tidy stack of rounded grey blobs in rows with white gaps -- too regular and too blobby beside the loose New England walls of the first two pictures. Next: more, smaller, flatter stones in five uneven courses, base wider than top, a dark core block so no sky shows through.
- r3: Five uneven courses on a dark core: a solid wall now, the right height beside the figure, but its top is ruler-straight and the core makes a dark box behind the stones. Next: a ragged top (more stones missing or proud on the top course), core lighter and lower.
- r4: Ragged top, lighter core: the top line is uneven now, but the core reads as a grey slab with stones painted on it. Next: core narrower (set back) and darker, so the stones stand proud and the gaps between them read as shadow.
- r5: Narrow dark core: the stones stand proud with shadow between them, a ragged top, lichen on some tops -- reads like the first two pictures' walls. The review along X is done; next: back along Y, as the game lays it (the sheet will show its end).
- r6: Back along Y, as the game lays it: the sheet shows its end -- a tapering profile a metre high beside the figure, wide at the foot, the dark core set back. 550 triangles, inside the panel budget. Next: hold.
