# Fairway 0.5 (beta)

Tag `v0.5`, published 2026-10-07.

The fifth beta of Fairway, and the first from its new home on GitHub, `doberloh/fairway-golf-simulator`, where its source code will be published.

**Nothing changes in how it plays.** 0.5 is the same game as 0.4: every course, every shot and every rule work exactly as they did. The move is behind the scenes: the website now lives apart from the game, so the game's code can be shared openly on its own.

**Getting started**

1. Unzip the whole download into a normal folder.
2. Run **run_fairway_server** and keep its window open. The first time, Windows and macOS warn about a program from the internet: on Windows choose *More info → Run anyway*; on a Mac, Control-click it and choose *Open*.
3. Open `http://127.0.0.1:1922` in your browser. On a phone or tablet, open the second link the window prints.

No launch monitor? Just open **Fairway.html** from the download. `Fairway-source.zip` is the source code, and `RELEASE_SHA256.txt` lists each file's checksum.

Your players, saved rounds and courses from 0.4 carry over, and every course grows exactly the same ground. This is a beta: it hasn't been tried with every launch monitor or every device, and a weak graphics card may struggle even on the lowest setting.
