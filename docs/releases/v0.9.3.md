# Fairway 0.9.3 (beta)

Tag `v0.9.3`, published 2026-10-22.

A security update to the tools that build Fairway. The game itself plays exactly as 0.9.2.

**What changed.** Fairway is built with a tool called Vite. Three security problems were found in the part of it that runs while the game is being developed. They never reached the game you download, but 0.9.3 is built with the fixed version anyway, so everything in this release comes from up-to-date tools.

**Nothing new to learn.** Every screen, setting and course is as it was in 0.9.2, and your rounds, courses, profiles and medals carry over. Courses grow exactly as before.

**One thing to know.** A friend's challenge code is tied to the version it was made on, so a code made on 0.9.2 plays only on 0.9.2. If you are playing a friend, make sure you both have 0.9.3.

**Getting started**

1. Unzip the whole download into a normal folder.
2. Run **run_fairway_server** and keep its window open (on Windows choose *More info → Run anyway*; on a Mac, Control-click and choose *Open*).
3. Open `http://127.0.0.1:1922` in your browser, or the second link it prints on a phone or tablet.

No launch monitor? Just open **Fairway.html**.

This is a beta: if something looks wrong, *Report a problem* in the help copies what we need.
